Mach3

Mach3 — программа управления станками ЧПУ. Она работает на компьютере под Windows, обрабатывает G-код и управляет движением станка. Разработчик: Newfangled Solutions (Artsoft).

На этой странице можно скачать демо-версию. Если нужна бессрочная версия, а не демо, свяжитесь с нами.

Скачать демо Mach3 R3.043 (26,5 МБ)
О демо-режиме. Без бессрочной версии программа запускается в демо-режиме. В демо-режиме для фрезеровки и плазмы действует ограничение в 500 строк G-кода, для токарной обработки ограничение составляет 50 строк.

Демо удобно, чтобы познакомиться с интерфейсом, проверить работу на коротких программах и понять, подходит ли Mach3 для вашего станка. Длинные рабочие управляющие программы в демо-режиме не запустить.

Установщик предназначен для Windows. Если станок подключается через параллельный порт (LPT), нужен настольный компьютер с 32-разрядной Windows (от Windows 2000 до Windows 7); ноутбуки и 64-разрядные системы в этом режиме не поддерживаются. Если используется внешний контроллер движения, программа работает и на ноутбуке, в том числе с 64-разрядной Windows, в линейке от Windows 2000 до Windows 10.

Полная бессрочная версия снимает ограничение по числу строк G-кода. Такую версию можно приобрести через нас.
