# universal-cnc
Официальный сайт программы "Универсал — система ЧПУ"

## Раздел «Шпиндели»

- Данные всех шпинделей — один файл `data/spindles.js` (массив `SPINDLES`).
- `spindle-changsheng.html` — список всех шпинделей (по брендам); `spindles/<slug>.html` — отдельная страница модели.
- Обе части и записи в `sitemap.xml` генерируются командой `node scripts/build-spindles.js` (страницы руками не правим).
- Новый шпиндель: добавить объект в `SPINDLES` (уникальные `id` и `slug`), фото — в `images/`, запустить скрипт, закоммитить.
- Фото модели: массив `photos` (пути от корня сайта, первое фото — главное). Старое поле `img` тоже поддерживается: главное фото = `photos[0]` или `img`. В списке и в marketplace показывается только главное фото.
- Дополнительное фото к существующей модели (другой ракурс, детали): положить файл в `images/` и добавить путь в `photos` этой модели, например:

      photos: [
        'images/tongsheng-thd80-2.2c-ru.jpg',
        'images/tongsheng-thd80-2.2c-ru-2.jpg'
      ]

  Затем выполнить `node scripts/build-spindles.js` и закоммитить файл фото, данные и сгенерированные страницы. На странице модели появится галерея: стрелки, миниатюры, счётчик «1 / N», пролистывание пальцем и полноразмерный просмотр по клику.
- Доп. информация по модели: `description` (абзацы описания), `applications` (применение), `notes` (`{date, text}` — сведения из писем), `clarify` (что уточняется), характеристики — в `specs`.
- Скрипт проверяет дубли id/slug, наличие каждого файла из `photos`, отсутствие дублей в массиве и отсутствие иероглифов.
